I help teams turn messy product requirements into dependable web, mobile, and API systems. My strongest work sits where scheduling, permissions, data ownership, integrations, location, and operational workflows need to work together—not just look good on a screen.

## Currently building

Physical-device transfers are working; interruption recovery, large-library behavior, and verified cleanup are now under hardware testing.
